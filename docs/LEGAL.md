## 2. 개인정보보호법 (PIPA)

### 2.1 수집 항목 (최소수집 원칙)

| 구분 | 항목 | 필수/선택 | 목적 | 보유 |
|---|---|---|---|---|
| 계정 | 소셜 로그인 식별자(sub), 이메일 | 필수 | 회원 식별·로그인 | 탈퇴 시까지 |
| 프로필 | 핸들, 닉네임, 소개, 아바타 | 필수(핸들)/선택 | 서비스 제공 | 탈퇴 시까지 |
| 콘텐츠 | 구절 본문, 작성일, 공개범위 | 필수 | 서비스 제공 | 탈퇴 시까지 |
| 기기 | 푸시 토큰, OS/앱 버전 | 선택 | 알림 발송 | 알림 해제/탈퇴 시 |
| 자동수집 | 접속 IP, 접속 일시, 기기 식별자 | 필수 | 부정이용 방지·법령 준수 | **확인 필요(법정 기간)** |
| 분석 | 이벤트 로그(가명/익명) | 선택 | 서비스 개선 | 1년 |

> Apple 로그인은 **이메일 가리기(Private Relay)** 를 지원한다. 릴레이 주소를 정상 처리하도록 설계할 것.
> 생년월일은 수집하지 않고 **"만 14세 이상입니다" 체크**로 대체하는 것이 최소수집 원칙에 부합(단, 실효성 한계는 감수).

### 2.2 동의 설계

- 동의 화면에서 **필수 / 선택을 분리**하고 개별 체크 제공
- 선택 동의(마케팅 수신, 분석) 거부해도 서비스 이용 가능해야 함
- 동의 시각·버전·IP를 **동의 이력 테이블에 저장** (입증 책임은 사업자에게 있음)
- 약관·처리방침 변경 시 사전 공지(중요 변경은 시행 30일 전 권장, **확인 필요**) 및 재동의

### 2.3 만 14세 미만

v1 방침: **만 14세 미만 가입 불가**. 가입 시 연령 확인 체크 + 약관 명시. 미만 확인 시 계정 정지·삭제 절차.
(법정대리인 동의 절차를 구현하면 허용 가능하나 MVP에는 과함)

### 2.4 개인정보 처리 위탁 / 국외 이전

| 수탁자 | 업무 | 소재 | 조치 |
|---|---|---|---|
| Supabase (또는 대체 클라우드) | 데이터 보관·인증 | **해외 가능성** | 처리방침 고지, 국외 이전 요건 검토 |
| Expo Push / APNs / FCM | 푸시 발송 | 해외 | 처리방침 고지 |
| PostHog / Amplitude | 분석 | 해외 | 가명처리 후 전송, 선택 동의 |

> **핵심 리스크**: 국내 이용자 개인정보의 국외 이전은 처리방침 고지 및 별도 요건이 붙는다(개인정보보호법 §28조의8, **확인 필요**). 이전 국가·수탁자·항목·목적·보유기간을 처리방침에 명시해야 한다. 이를 피하려면 **국내 리전(AWS 서울 / NCP)** 을 선택한다. PRD §6 미결정 사항과 연결.

### 2.5 안전성 확보조치

| 항목 | 구현 |
|---|---|
| 전송 구간 암호화 | 전 구간 HTTPS/TLS |
| 저장 암호화 | 인증 정보·토큰 암호화 저장, DB 저장 시 암호화 |
| 접근 통제 | 운영 콘솔 2FA, 최소 권한, 서비스 키 서버 전용(클라이언트 anon key와 분리) |
| 접속 기록 | 개인정보처리시스템 접속기록 보관·점검 (보관 기간 **확인 필요**) |
| 백업 | 일 단위 백업, 복구 테스트 |
| 취약점 | 출시 전 기본 점검, RLS 정책 테스트 케이스 필수 |

### 2.6 유출 대응

인지 시점 기준 **72시간 내** 정보주체 통지, 일정 규모 이상은 보호위원회·KISA 신고 (기준 수치 **확인 필요**). 대응 절차·연락 체계를 사전에 문서화한다.

### 2.7 이용자 권리

열람 / 정정 / 삭제 / 처리정지 요구 창구를 앱 내 제공(이메일 가능). 요청 접수 후 처리 기한 준수(**확인 필요**). 계정 삭제는 앱 내 즉시 실행 가능해야 함(B5).

## 3. 정보통신망법 — 알림·광고

| 알림 종류 | 성격 | 요건 |
|---|---|---|
| 작성 리마인더 | 이용자가 직접 설정한 **서비스 알림** | 광고 아님. 단, 문구에 마케팅성(이벤트·혜택) 섞이면 광고로 간주됨 |
| 공감·새 팔로워 | 서비스 알림 | 동일 |
| 이벤트·업데이트 홍보 | **광고성 정보** | 사전 수신 동의 필수, 제목에 `(광고)` 표기, 수신거부 방법 명시 |

| 수신 동의 확인 | — | 정기적으로 수신 동의 여부 재확인 (주기 **확인 필요**) |

> 실무 주의: 리마인더 푸시 시간을 유저가 야간으로 설정할 수 있다. 서비스 알림이므로 원칙상 가능하나, **문구에 마케팅 요소가 섞이면 위반**이 된다. 리마인더 문구는 순수 기능성으로 고정할 것.

## 4. 게시물 관리 — 권리침해와 임시조치

| 절차 | 내용 |
|---|---|
| 권리침해 신고 창구 | 앱 내 신고 + 이메일 창구. 신고 양식(신고인, 대상 URL/ID, 침해 사유) |
| 임시조치 | 명예훼손·사생활 침해 신고 접수 시 **지체 없이 삭제 또는 30일 이내 임시조치(블라인드)** (정보통신망법 §44-2, 세부 **확인 필요**) |
| 작성자 통지 | 임시조치 시 작성자에게 사실 통지 + 이의신청 절차 안내 |
| 자체 조치 | 명백한 불법·유해 게시물에 대한 임의 임시조치 근거를 **약관에 명시** |
| 기록 보관 | 신고·조치·이의 이력 보관 |

|---|---|

| 스팸·광고 | 48시간 내 |

## 5. 청소년 보호

- 만 14세 이상 서비스이나 **청소년 이용 가능 등급**을 전제로 운영

- 신고 카테고리에 "자해·자살 위험" 항목 포함

## 6. 저작권 — 이 앱의 최대 고유 리스크

"구절"을 쓰는 앱이라는 성격상 **명언·시·가사·책 문장 전재**가 대량 발생할 것이 예상된다. 가사·시 전문 게시는 복제권·공중송신권 침해가 될 수 있다.

| 대응 | 구현 |
|---|---|
| 작성 가이드 | 에디터 하단 안내: "타인의 글·가사·시를 그대로 옮기면 저작권 침해가 될 수 있습니다" |
| 약관 | 이용자가 자신의 창작물임을 보증하고, 침해 시 이용자 책임임을 명시 |
| 인용 표기 | 인용 시 출처 표기 유도(별도 필드는 v1.1) |
| 통지·삭제 절차 | 저작권자 신고 → 복제·전송 중단 → 작성자 통보 → 재개 요구 절차 (저작권법상 OSP 책임 제한 요건, **확인 필요**) |
| 반복 침해자 | 3회 누적 시 계정 정지 정책 명시 |
| 라이선스 | 이용자 콘텐츠에 대해 **서비스 운영에 필요한 범위의 비독점 사용권**만 약관에 규정 (과도한 권리 요구는 반발을 산다) |

## 8. 데이터 보관·파기 정책

| 데이터 | 보관 | 파기 |
|---|---|---|
| 계정·프로필 | 탈퇴 시까지 | 탈퇴 즉시 파기 |
| 구절·공감·팔로우 | 탈퇴 시까지 | 탈퇴 즉시 파기 |

## 10. 개발 체크리스트

- [ ] 온보딩에 만 14세 이상 확인 + 약관/처리방침 동의(필수·선택 분리)
- [ ] 동의 이력 테이블 저장(버전·시각·IP)
- [ ] 설정 → 계정 삭제 (앱 내 완결, 즉시 파기)
- [ ] 신고(게시물/유저) + 차단 + 숨기기
- [ ] 신고 카테고리에 자해·자살, 저작권 침해 포함
- [ ] 자해·자살 키워드 감지 시 상담 안내 배너
- [ ] 알림 설정 분리: 리마인더 / 공감 / 팔로워 / (마케팅 = 선택 동의)
- [ ] 마케팅 푸시에 `(광고)` 표기 + 야간 전송 차단 로직
- [ ] 관리자 도구: 신고 큐, 임시조치(블라인드), 제재, 이력
