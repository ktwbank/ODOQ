# ODOQ 화면 정의 (v0.1)

## 탭 1. 오늘 (Today)

| 상태 | 화면 |
|---|---|
| 미작성 | 날짜 + "오늘의 한마디" 입력창(140자 카운터) + 공개/비공개 토글 + [남기기] |
| 작성 완료 | 오늘 쓴 글 카드 + 스트릭(N일째) + [수정] [삭제] + "피드 보러 가기" |

- 입력은 풀스크린 에디터, 키보드 자동 포커스. 자동 임시저장(로컬).
- 빈 화면 방지: 작성 전 프롬프트 문구 1개 노출(예: "오늘 가장 오래 머문 생각은?") — 선택적 힌트일 뿐 강제 아님.

## 탭 2. 피드 (Feed)

- 세그먼트: `전체` / `팔로잉` (기본값 = 전체)
- 카드 구성: 작성자 핸들·아바타 / 본문 / 상대시간 / 공감 버튼 + 카운트
- 전체 탭: 최근 24시간 공개 글, 최신순, 차단 유저 제외
- 팔로잉 탭: 팔로잉 유저의 공개 글, 최신순. 비어 있으면 추천 유저 3~5명 노출
- 인터랙션: 카드 탭 → 글 상세 / 아바타 탭 → 타인 프로필 / 길게 누르기 → 신고·차단

## 탭 3. 기록 (Archive)

- 상단 월 캘린더: 글 쓴 날 점 표시, 날짜 탭 → 해당 글
- 하단 리스트: 최신순, 비공개 글은 자물쇠 아이콘
- 월별 요약: 이번 달 작성 N일 / 최장 스트릭

## 탭 4. 프로필 (Profile)

- 아바타, 핸들, 소개 1줄, 팔로워/팔로잉 수, 총 작성 수
- 내 프로필: 공개 글만 보이는 "남들이 보는 화면" 미리보기 제공
- 설정 진입: 알림 시간, 차단 목록, 약관/개인정보, 로그아웃, **계정 삭제**

## 스택 화면

| 화면 | 요소 |
|---|---|
| 글 상세 | 본문, 작성자, 공감, 신고/차단 (본인 글이면 수정·삭제) |
| 타인 프로필 | 팔로우/언팔로우 버튼, 공개 글 리스트, 차단·신고 |
| 팔로워/팔로잉 | 리스트 + 각 행 팔로우 버튼 |
| 온보딩 | 로그인 → 핸들 설정(중복 검사) → 알림 권한 → 첫 글 작성 유도 |

## 엣지 케이스

| 상황 | 처리 |
|---|---|
| 자정 경과 중 작성 | 제출 시각의 로컬 날짜 기준. 서버는 `entry_date`를 클라이언트 타임존으로 계산해 저장 |
| 타임존 변경(여행) | `entry_date` 유니크 제약 충돌 시 "오늘은 이미 작성했습니다" 안내 |
| 오프라인 작성 | 로컬 큐에 저장 후 온라인 시 동기화. 충돌 시 로컬 우선 |
| 차단한 유저 | 양방향 비노출(피드·프로필·팔로워 목록 전부) |
| 신고된 글 | 신고 3건 누적 시 자동 비노출 + 검토 큐 (초기엔 수동 검토) |
| 계정 삭제 | 글·팔로우·공감 전부 하드 삭제, 30일 유예 없음(단순화) |
