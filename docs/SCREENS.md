# ODOQ 화면 정의 (v0.2)

탭 구조: `홈` / `쓰기` / `기록` / `프로필`

---

## 온보딩 (액티베이션 구간 — 가장 중요한 화면)

| 단계 | 화면 | 이탈 방지 |
|---|---|---|
| 1 | 소개 3장 (하루의 감상을 한 구절로 / 다른 사람의 구절을 읽고 / 팔로우) | 스킵 버튼 |
| 2 | 로그인 (Apple / Google) | — |
| 3 | 약관·처리방침 동의 (필수/선택 분리) + **만 14세 이상 확인** | 법적 필수, 스킵 불가 |
| 4 | 핸들 설정 (중복 검사, 추천 핸들 제시) | 자동 생성값 제공 |
| 5 | **관심 토픽 선택** (3개 이상, 6~8개 제시) | 3개 미만이면 "아무거나 골라도 나중에 바꿀 수 있어요" |
| 6 | **추천 유저 팔로우** (토픽별 8~12명, 기본 선택 상태) | 건너뛰기 허용. 단 팔로우 0명이면 다음 화면에서 재유도 |
| 7 | 알림 권한 + 리마인더 시간 설정 | 나중에 하기 |
| 8 | 팔로잉 피드 진입 (이미 콘텐츠가 차 있음) | — |
| 9 | 첫 구절 작성 유도 배너 | 24h 내 미작성 시 푸시 1회 |

> 6번이 비면 8번이 빈 화면이 되고 그 유저는 돌아오지 않는다. 추천 풀은 항상 최소 30명 이상 유지할 것.

## 탭 1. 홈 (피드)

- 세그먼트: `추천` / `팔로잉` — 기본값은 **팔로잉**(온보딩에서 팔로우를 채웠으므로), 팔로잉 0명이면 추천
- 카드: 아바타·핸글·상대시간 / 본문 **4줄에서 접기 + 더보기** / 공감 버튼·카운트
- 500자 전문은 상세 화면에서
- 추천 탭: 추천 알고리즘(PRD §3) 결과 + 신규 크리에이터 보정, 무한 스크롤
- 팔로잉 탭: 팔로잉 유저 공개 구절, 최신순
- 롱프레스: 신고 / 차단 / 이 사용자 글 숨기기

## 탭 2. 쓰기

| 요소 | 사양 |
|---|---|
| 에디터 | 풀스크린, 키보드 자동 포커스, 500자 카운터(450자부터 색 변경) |
| 프롬프트 | 상단에 오늘의 질문 1개 (예: "오늘 하루가 남긴 한 문장은?") — 비강제 힌트 |
| 공개 범위 | 기본 `공개`, 토글로 비공개 |
| 대표 지정 | 오늘 첫 글은 자동으로 대표. 2번째부터는 "오늘의 대표 구절로 지정" 체크 |
| 저작권 안내 | 하단 1줄 고지 (타인의 글·가사 전재 주의) |
| 임시저장 | 로컬 자동 저장, 앱 재진입 시 복원 |
| 작성 후 | 완료 애니메이션 + "누적 134일째" + 피드로 이동 |

## 탭 3. 기록 (내 아카이브)

- 월 캘린더: 작성일에 점, **대표 구절만** 미리보기. 날짜 탭 → 그날의 모든 구절
- 리스트 뷰 전환 가능, 비공개 글은 자물쇠 아이콘
- 월 요약: 이번 달 작성 N일 / 누적 N일 / 받은 공감 N

## 탭 4. 프로필

- 아바타, 핸들, 소개(80자), 팔로워·팔로잉 수, 누적 구절 수, 누적 작성일
- 내 프로필: "남들이 보는 화면" 미리보기 토글
- 설정
  - 알림: 리마인더(시간 지정) / 공감 / 새 팔로워 / 마케팅(선택 동의)
  - 차단 목록 관리
  - 약관 · 개인정보처리방침 · 커뮤니티 가이드라인 · 운영정책 · 오픈소스 고지 · 사업자 정보
  - 문의하기 (앱 내 연락 수단 — 스토어 심사 요건)
  - 로그아웃 / **계정 삭제**

## 스택 화면

| 화면 | 요소 |
|---|---|
| 구절 상세 | 전문 500자, 작성자, 공감, 신고·차단 (본인 글이면 수정(24h)·삭제·대표 지정) |
| 타인 프로필 | 팔로우 버튼, 공개 구절 리스트, 차단·신고 |
| 팔로워/팔로잉 | 리스트 + 행별 팔로우 버튼 |
| 신고 | 카테고리 선택(스팸 / 혐오·폭력 / 성적 / 명예훼손·사생활 / **저작권 침해** / **자해·자살 위험** / 기타) + 상세 입력 |
| 신고 완료 | "24시간 내 검토합니다" + 해당 유저 차단 제안 |
| 상담 안내 | 자해·자살 키워드 감지 시 전면 배너 (전문 상담 연결 안내) |

## 엣지 케이스

| 상황 | 처리 |
|---|---|
| 하루 여러 개 작성 | 허용. 대표 구절 1개만 캘린더·프로필 그리드에 노출 |
| 대표 구절 삭제 | 같은 날 다른 글이 있으면 가장 오래된 글이 자동 승계, 없으면 그날은 빈 날 |
| 자정 경과 중 작성 | 제출 시각의 **작성자 로컬 날짜**를 `entry_date`로 저장 |
| 타임존 변경 | 유니크 제약이 없으므로 충돌 없음. 대표 구절만 날짜별 1개 보장 |
| 오프라인 작성 | 로컬 큐 저장 → 온라인 시 동기화 |
| 차단 | 양방향 비노출(피드·프로필·팔로워 목록·공감 전부) |
| 신고 누적 | open 신고 3건 또는 운영자 조치 시 `is_hidden=true` (임시조치) + 작성자에게 통지·이의신청 안내 |
| 임시조치된 글 | 작성자 본인에게는 "검토 중" 상태로 노출 |
| 계정 삭제 | 구절·팔로우·공감 즉시 파기. 신고 이력은 법적 근거 범위 내에서만 가명 보관 |
| 500자 초과 붙여넣기 | 입력 차단 + "500자까지 쓸 수 있어요" 토스트 |
