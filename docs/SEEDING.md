# ODOQ 시딩 실행 계획 (v0.1)

목표: 공개 출시 시점에 **신규 유저가 첫 화면에서 빈 피드를 보지 않는 것**. 그 외 목표는 없다.

## 수치 목표

| 항목 | 목표 | 산식 |
|---|---|---|
| 시드 크리에이터 | 80명 | — |
| 시드 구절 | 1,120개 | 80명 × 14일 × 1구절 |
| 토픽당 활동 크리에이터 | 12명 이상 | 80명 / 6~7토픽, 편중 보정 필요 |
| 추천 풀 최소 크기 | 30명 (상시) | 온보딩 카드 8~12명 × 3회 갱신 |

> 산식 근거: 온보딩에서 8~12명을 보여주고 3명 팔로우를 유도한다. 같은 얼굴만 계속 나오면 추천의 신뢰가 깨지므로 토픽당 최소 12명이 필요하다. 1,120구절이면 신규 유저가 팔로잉 피드에서 최소 40~60개 카드를 스크롤할 수 있다(3명 팔로우 × 14구절 = 42).

## 단계

| 주차 | 활동 |
|---|---|
| W-6 | 시드 크리에이터 후보 리스트업(글쓰기 뉴스레터 필자, 북스타그램, 문장 수집 계정) 200명 |
| W-5 | 개별 컨택, 초대코드 발송. 목표 수락률 40% → 80명 |
| W-4~W-2 | 클로즈드 베타. 하루 1구절 요청. 주 1회 리마인드 |
| W-2 | 톤 이탈(일기형) 콘텐츠 피드백, 토픽 태깅 |
| W-1 | 추천 화이트리스트 확정, 온보딩 추천 카드 구성 |
| W0 | 공개 출시 |

## 시드 크리에이터 조건

- 보상: 초기 크리에이터 배지, 추천 피드 우선 노출, 크레딧 등재
- **금전 보상은 v1에서 배제** — 지급 시 계약·원천징수 문제가 생기고, 돈으로 유지되는 콘텐츠는 지급 중단 시 함께 사라진다
- 요구: 2주간 하루 1구절, 일기가 아닌 감상형 문장

## 톤 가이드 (크리에이터 배포용)

| 구분 | 예시 |
|---|---|
| O (감상·통찰) | "잘 지내냐는 말에 대답을 고르는 시간이 길어졌다." |
| X (일기) | "오늘 친구랑 강남에서 파스타 먹고 카페 갔다." |
| X (저작권) | 노래 가사·시 전문 인용 |

## 시딩 이후 — 자립 조건

시딩의 성공은 "시드 크리에이터가 떠나도 서비스가 유지되는가"로 판정한다.

| 지표 | 자립 기준(가설) |
|---|---|
| 신규 유저의 팔로잉 중 비시드 비율 | 출시 8주차에 50% 이상 |
| 시드 외 유저가 만든 구절 비율 | 8주차에 70% 이상 |
| 시드 크리에이터 잔존율 | 8주차 40% 이상 (이하로 떨어지면 추천 풀 재구성) |

> 실패 시나리오: 시드 80명만 계속 추천되고 신규 유저는 글을 쓰지 않는 **관객화**. 이 경우 추천 알고리즘에 "최근 가입·소량 작성자 노출 보정"을 넣어 신규의 첫 공감 경험을 만들어야 한다. 첫 구절에 공감 0이면 두 번째 구절은 없다.
