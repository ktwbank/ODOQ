# ODOQ — One Day One Quote

오늘 하루의 감상을 짧은 구절로 남기고, 다른 사람의 구절을 읽고 팔로우한다.
일기가 아니라, 남이 읽어도 의미 있는 범용적인 문장.

## 핵심 규칙

| 항목 | 값 |
|---|---|
| 작성 횟수 | 제한 없음 (하루 1구절은 권장 리듬, 강제 아님) |
| 대표 구절 | 하루 1개를 대표로 지정 — 캘린더·프로필의 단위 |
| 글자 수 | 500자 |
| 반응 | 공감만. **댓글 없음** |
| 관계 | 팔로우 (승인 불필요) |
| 성장 | 시딩 → 액티베이션(온보딩 추천 팔로우) → 리텐션 |
